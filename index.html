objectに入るプロパティ
    position: 座標
    shape: 形{rect:長方形(pointsに左上と右下の座標),circle:円(sizeの代わりにradius,triangle:三角形(pointsに上、左、右の座標),polygon:多角形(pointsに好きな数の座標)}
    visible: 描画されるかされないかでtrueかfalseをつける。
    opacity: opacity 透明度で透明度を設定できる。1が最大
    rotate: rotate 角度で回転を設定できる。
    
objectにできること
    draw: canvas object drawで描画
    distance: let d = オブジェクト1 distance オブジェクト2でオブジェクト1からオブジェクト2の中心座標の距離を取得
    collision: let hit = オブジェクト1 collision オブジェクト2でオブジェクト1とオブジェクト2が重なっているかを調べ、trueかfalseを返す。

Object properties

    position:
        Coordinates

    shape:
        Shape

        rect:
            Rectangle

        circle:
            Circle

        triangle:
            Triangle

        polygon:
            Polygon

    visible:
        Whether the object is drawn.
        Use true or false.

    opacity:
        Transparency.
        1 is fully visible.

    rotate:
        Rotation angle.


Object operations

    draw:
        Draw the object.

        direction:
        right
        left
        up
        down
        or an angle

    distance:
    　　let d = object1 distance object2
        Gets the distance between
        the centers of two objects.

    collision:
        let hit = object1 collision object2
        Checks whether two objects
        overlap and returns true or false.


(Variables can be used.)

(Object properties can be reassigned.)
